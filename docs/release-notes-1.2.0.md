# Atelier 1.2.0

Atelier 1.2.0 is a stable release. It brings the changes from the
1.1 preview series into the stable channel and adds improvements to
window management, page organization, and crash recovery.

- Reorder tabs by dragging, move them between Atelier windows, or detach
  them into a new window. Reopen a closed tab at its previous page and zoom.
- On Windows, reveal the active file in File Explorer. The tab menu also
  offers Copy File Path.
- Choose a popup menu, an expandable toolbar menu, or a separate top menu
  row where supported. macOS continues to provide its native menu bar.
- Auto-orientation prioritizes the first three pages. OCR processes pages
  concurrently with a configurable limit and makes each page searchable
  as it finishes.
- Find likely blank pages in Organize Pages, review the candidates, and
  remove the selected pages.
- Recover unsaved changes from local checkpoints for unencrypted PDFs,
  including in-progress form text and ink. Restored drafts open as
  unsaved documents so you can choose where to save them.
- Inspect later changes to signed PDFs by revision. Recognized form and
  annotation changes appear beside the signature verification results.

Downloads include Windows x64 installers and portable builds, Windows
x64 FIPS variants, macOS ARM64, and Linux x64 and ARM64. Use the included
SHA-256 manifest to check the downloads. The Windows and macOS packages
may trigger operating-system warnings because the Windows executables
are unsigned and the macOS app is ad-hoc signed.
