# Atelier 1.2.2

Atelier 1.2.2 adds secure redaction to the main PDF workspace.

- Open **File → Secure Redaction…** to mark an area, select text, click an image, or select detected table cells. Use the normal zoom, pan, and page navigation while reviewing marks.
- Export a separate PDF that keeps supported text selectable and preserves vectors and image content outside the marks. Supported content includes embedded outline fonts, Identity-V vertical text, Type 3 vector and inline stencil glyphs, and inline images with verifiable boundaries.
- Atelier reopens and verifies the new PDF before saving. The export omits annotations, forms, attachments, document metadata, and revision history. **Export page images** is available for pages whose contents cannot be verified in vector mode.

The release includes Windows, macOS, and Linux packages.
