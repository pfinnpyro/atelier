# Atelier 1.2.1

This patch improves the page organizer and fixes page previews after auto-rotation.

- Choose one of six preview zoom levels from 75% to 200%. Previews render at a higher resolution as you zoom in.
- Drag the handle next to the page number to reorder a page or a selected group. The preview follows the pointer, and a marker shows the drop position.
- Use **Delete** or **Export…** below a preview to remove that page or save it in a separate PDF.
- **Find blank pages** also lists otherwise blank scans with narrow copier streaks, including rotated scans. Streak candidates start unchecked and can be selected together for review.

Downloads include Windows x64 installers and portable builds, Windows x64 FIPS variants, macOS ARM64, and Linux x64 and ARM64. The SHA-256 manifest covers all release packages.
